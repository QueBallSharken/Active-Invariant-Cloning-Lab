# Experiments

## Purpose

This directory contains experiments designed to test claims made by the Active Invariant Cloning (AIC) repository.

Experiments exist to generate evidence.

Experiments do not exist to defend assumptions.

---

# Experiment Principles

Experiments should be:

- Reproducible
- Measurable
- Documented
- Reviewable

Whenever practical, experiments should be repeatable by independent contributors.

---

# Evidence Rule

Experimental outcomes may include:

- Success
- Failure
- Partial success
- Inconclusive results

All outcomes are valuable when documented accurately.

---

# Experiment Categories

Potential experiment categories include:

- Clone survivability
- Semantic equivalence
- Drift detection
- Clone disagreement
- Governance participation
- Refusal capability
- Hidden mutation path discovery

---

# Repository Rule

Evidence produced by experiments takes precedence over assumptions.

If an experiment contradicts a theory:

The experiment wins.

---

# Final Statement

This directory exists to generate evidence regarding Active Invariant Cloning.

Evidence wins.
