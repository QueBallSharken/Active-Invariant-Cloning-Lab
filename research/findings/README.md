# Findings

## Purpose

This directory contains findings generated through experimentation, testing, measurement, and verification.

Findings represent observed results.

Findings are not assumptions.

Findings are not hypotheses.

Findings should be supported by evidence whenever practical.

---

# Finding Requirements

A finding should identify:

- What was tested
- How it was tested
- What was observed
- Supporting evidence
- Known limitations

---

# Finding Categories

Potential categories include:

- Clone survivability findings
- Semantic equivalence findings
- Drift detection findings
- Governance findings
- Failure findings
- Adversarial findings

---

# Repository Rule

Findings should accurately represent observed outcomes.

Findings should not be modified to support preferred conclusions.

Evidence remains authoritative.

---

# Relationship To Experiments

Experiments generate evidence.

Findings summarize what that evidence suggests.

Future experiments may confirm, refine, or contradict previous findings.

---

# Final Statement

This directory exists to preserve evidence-supported observations generated during Active Invariant Cloning research.

Evidence wins.
