Receipts

Purpose

This directory contains evidence generated through implementation, experimentation, testing, and verification.

Receipts provide traceable support for repository findings.

---

Evidence Types

Examples may include:

- Test results
- Measurements
- Execution records
- Clone survivability records
- Drift detection records
- Verification artifacts

---

Evidence Rule

Evidence should be preserved whenever practical.

Evidence takes priority over assumptions.

Evidence takes priority over preferences.

Evidence takes priority over conclusions.

---

Repository Principle

Claims should be supported by receipts whenever possible.

If evidence contradicts assumptions:

Evidence wins.

---

Final Statement

This directory exists to preserve the evidence produced by the repository.
