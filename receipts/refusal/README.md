# Refusal Receipts

Repository: Active Invariant Cloning Lab

---

# What Is A Refusal Receipt?

A refusal receipt is an evidence artifact demonstrating that a mutation request was prevented by one or more active invariant clones.

The purpose is to verify that clones remain:

- Live
- Binding
- Refusal-Capable

during governance activities.

---

# Evidence Principle

Refusal is a core governance behavior.

Detection alone is insufficient.

Warning alone is insufficient.

A refusal receipt should demonstrate that refusal authority remained effective.

---

# Receipt Contents

Whenever practical, refusal receipts should include:

- Receipt identifier
- Timestamp
- Request
- Governing invariant
- Participating clones
- Refusal decision
- Final outcome
- Supporting references

Refusal receipts provide evidence for:

# Repository Rule

Refusal receipts should document observed outcomes.

Receipts should not be modified to support preferred conclusions.

Evidence remains authoritative.

---

# Historical Preservation Rule

Refusal evidence should be preserved whenever practical.

Negative outcomes remain valuable evidence.

Failures should be documented.
