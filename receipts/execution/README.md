---

# What Is An Execution Receipt?

An execution receipt is a record demonstrating that a specific governance event occurred.

A receipt should allow future reviewers to understand:

- What was executed
- What was evaluated
- Which clones participated
- What decisions were produced
- What outcome occurred

---

# Evidence Principle

Receipts exist to preserve evidence.

Receipts are not explanations.

Receipts are not assumptions.

Receipts are records of observed execution.

---

# Receipt Contents

Whenever practical, receipts should include:

- Receipt identifier
- Timestamp
- Request
- Clone identifiers
- Clone decisions
- Agreement state
- Final outcome
- Supporting references
