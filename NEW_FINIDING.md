which paths are mandatory, and what happens if the evidence

    PROVENANCE ≠ ENFORCEMENT

unless the enforcement semantics are explicitly encoded in
the terminal acceptance predicate.

    LTL TRACE PROPERTY ≠ COMPLETE AIC PROPERTY

unless the trace model contains the relevant mandatory-path,
binding, freshness, state, and rejection semantics.

in the original counterfactual sense.

    PATH ENFORCEMENT INTEGRITY

preservation of mandatory enforcement conditions from mutation
origin through the scoped terminal mutation authority.

can be defined over:

    1. a declared path model,
    2. mandatory enforcement boundaries,
    3. explicit acceptance/rejection transitions,
    4. mutation identity,
    5. state/version binding where required,
    6. terminal acceptance rules.

AIC therefore survives Round-2 only as a narrowed,
operationally specified governance property.
