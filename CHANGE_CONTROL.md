Change Control

Purpose

This repository is not currently an architecture redesign effort.

This repository is an implementation, experimentation, and validation effort.

The purpose is to determine whether Active Invariant Cloning (AIC) can be realized, tested, measured, and verified.

---

Repository Rule

Contributors must not introduce:

- New foundational architectures
- New governance models
- New replacement frameworks
- New directional pivots
- New conceptual substitutions

unless explicitly requested by the repository owner.

---

Current Objective

The objective is:

Define

Implement

Test

Measure

Verify

Document

The objective is not:

Assume success

Assume failure

Redesign the repository mission

Replace Active Invariant Cloning

---

Direction Lock

The following concepts are considered established for testing purposes:

- Active Invariant Cloning
- Clone Survivability
- Semantic Equivalence
- Clone Drift Detection
- Clone Legitimacy
- Governed Execution
- Refusal-Capable Clones

These concepts are to be tested.

Not replaced.

---

Contributor Requirement

Before proposing a change ask:

Is this required to test the existing claim?

If NO:

Do not propose it.

---

Repository Priority

1. Reproduce
2. Implement
3. Test
4. Measure
5. Verify
6. Document

Only after verification may redesign discussions occur.

---

Architectural Freeze

The repository remains focused on validation until:

- A clone model is defined
- Semantic equivalence requirements are defined
- Clone survivability metrics are defined
- A governed execution prototype exists
- Drift detection mechanisms are tested

Until then:

Implementation outranks innovation.

Evidence outranks preference.

---

Final Rule

This repository exists to determine whether previously developed claims are true.

Not to replace them before they have been tested.

Evidence wins.
