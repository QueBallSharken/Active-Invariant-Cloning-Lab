Tests

Purpose

This directory contains validation activities for Active Invariant Cloning (AIC).

Testing exists to determine whether repository claims survive implementation and adversarial scrutiny.

---

Test Categories

Future test categories may include:

- Unit Tests
- Integration Tests
- Adversarial Tests
- Survivability Tests
- Drift Detection Tests

---

Testing Rule

Claims are not considered validated until they have been tested.

Assumptions should be challenged whenever practical.

Failure is evidence.

Success must be reproducible.
